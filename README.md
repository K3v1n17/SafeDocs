## 📄 Descripción

**SafeDocs Frontend** es la interfaz de usuario de la aplicación SafeDocs.  
Permite a los usuarios autenticarse, gestionar documentos y acceder a la información de manera segura, comunicándose con el backend a través de una **API REST**.

El proyecto fue desarrollado con fines **académicos**, priorizando la usabilidad y la claridad visual.

---

## 🚀 Funcionalidades Principales

- Autenticación de usuarios  
- Visualización y gestión de documentos  
- Carga de documentos  
- Interacción con la API del backend  
- Manejo de estados y validaciones en la interfaz  

---

## 🛠️ Tecnologías Utilizadas

- **Framework:** React  
- **Lenguaje:** JavaScript / TypeScript  
- **Estilos:** CSS / Tailwind / Material UI *(ajustar según corresponda)*  
- **Comunicación con backend:** API REST
